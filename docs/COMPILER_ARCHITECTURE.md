# Impulse Graph Compiler Architecture & openCypher Frontend

The **Impulse Graph Compiler** is a polyglot, 7-stage optimizing intermediate representation (IR) compiler that lowers declarative graph queries—authored in **openCypher**, **ImpK** (GraphBLAS array DSL), **ImpLog** (Datalog logic rules), or **ImpScheme** (homoiconic S-expressions)—directly into register-allocated **`impOps` binary bytecode** for zero-allocation SIMD execution on the `ImpulseVM`.

## 2. openCypher Query Frontend & Invariants

The Impulse openCypher frontend supports analytical multi-hop graph pattern matching (`MATCH ... WHERE ... RETURN`) under three strict performance contracts:

1. **Strict Set Semantics (Zero Combinatorial Path Explosion)**:
   - Intermediate traversal frontiers operate strictly on deduplicated off-heap BitSets ($O(V)$ bit vectors), avoiding Cypher's $O(k^d)$ path duplication.
2. **Mandatory Typed Edge Walks**:
   - Untyped anonymous walks `(a)-->(b)` are rejected at compile-time with clear schema diagnostics. Every traversal MUST specify an explicit relation (e.g. `[:DaG]`, ``[:`DRUGBANK::ddi_interactor_in`]``).
3. **Disallow Unbounded / Infinite Walks**:
   - Unbounded wildcards `[:Rel*]` without an upper bound are rejected at compile-time. Variable-length hops require explicit bounds (e.g. `[:Rel*1..4]`).

### Example openCypher Queries & Generated Bytecode

#### Q1: 4-Hop Pathway-Based Drug Repurposing (Hetionet)
```cypher
MATCH (d:Disease)-[:DaG]->(g1:Gene)-[:GpPW]->(p:Pathway)<-[:GpPW]-(g2:Gene)<-[:CbG]-(c:Compound)
WHERE d.id = $diseaseId
RETURN c
```

**Emitted `impOps` Assembly (`.impas`)**:
```assembly
.version 0.9.0
.instructions 6

  0x0000:  OP_CSR_WALK              flags=0x03, dst=R1 , payload=0x00070000 ; Walk src=R0 -> dst=R1 via rel[7] ("DaG") [seed-inlined] [early-exit]
  0x0001:  OP_CSR_WALK              flags=0x01, dst=R0 , payload=0x00140001 ; Walk src=R1 -> dst=R0 via rel[20] ("GpPW") [early-exit]
  0x0002:  OP_CSC_WALK              flags=0x01, dst=R1 , payload=0x00140000 ; Walk src=R0 -> dst=R1 via rel[20] ("GpPW") [early-exit]
  0x0003:  OP_CSC_WALK              flags=0x01, dst=R0 , payload=0x00130001 ; Walk src=R1 -> dst=R0 via rel[19] ("CbG") [early-exit]
  0x0004:  OP_COLLECT_BITSET        flags=0x00, dst=R0 , payload=0x00000000 ; Collect active result bitset from R0
  0x0005:  OP_HALT                  flags=0x00, dst=R0 , payload=0x00000000 ; Execution complete
```
